# Architecture Documentation

This directory describes the current v7 system boundary and operational model.
`v7.md` is the maintained kernel, plugin, runtime, event, action, and
performance overview. Keep it synchronized with `docs/specs/` and current
implementation; do not use it as a proposal log.

- [Cordis Plugin v1](cordis-plugin-v1.md) records the accepted Beta6 package,
  host discovery, composition, lifecycle, and audit contract.
- [Cordis adoption boundaries](cordis-adoption-boundaries.md) records the
  trust, access, and broker boundaries behind the model.
- [Cordis design comparison](cordis-design-comparison.md) distinguishes this
  Python composition layer from Koishi compatibility and runtime bridges.
