# Architecture Documentation

This directory describes the current v7 system boundary and operational model.
`v7.md` separates implemented kernel/runtime behavior from the accepted
Multiplane implementation direction. Keep it synchronized with `docs/specs/`
and current implementation; do not use it as a release plan or proposal log.

- [v7 architecture](v7.md) defines the current kernel and Multiplane boundary.
- [Cordis design comparison](cordis-design-comparison.md) compares Liteyuki's
  bounded processor-plane direction with Koishi and DeepSeek Harness.
- [Cordis adoption boundaries](cordis-adoption-boundaries.md) records which
  Cordis ideas are appropriate for Liteyuki and the criteria for future work.
