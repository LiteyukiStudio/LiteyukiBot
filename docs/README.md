# Documentation

This directory documents the implemented LiteyukiBot v7 Alpha15 boundary:

- `configuration.md` covers schema 7 and CLI configuration operations.
- `architecture/` covers the four distributions and Cordis lifecycle.
- `specs/` covers core event/action and SnowLuma OneBot behavior.
- `development/releasing.md` covers the four-package release graph.

Alpha15 publishes `liteyukibot-v7`, `liteyukibot-v7-kernel`,
`liteyukibot-v7-cordis`, and `liteyukibot-v7-adapter-onebot`, all at
`7.0.0a15`. Pre-Alpha15 code and documentation are preserved on Git branch
`archive/20260827`; they are not current guidance.

Public contract changes require a matching focused test and documentation
update.
