# Legacy Bridge Source Snapshots

The directories here are retained source snapshots, not LiteyukiBot v7.0.0
mainline packages. They are excluded from the uv workspace, dependency lock,
CI, release bundles, publish workflows, install verifiers, and supported
documentation.

Do not import or depend on these projects from mainline code. Restoring one as
an opt-in add-on requires a new ownership and support decision, current
dependencies, independent CI and release validation, and an explicitly
approved package identity.

Git history remains the authoritative record of their former mainline state.
